# v2.7.13

- 播放页新增黑胶唱片样式：唱片随播放旋转，暂停时停在当前角度
- 长按封面任意位置（含盘面空白处）弹出样式面板，可切换原始封面 / 黑胶唱片
- 新增「修改背景」：渐变（默认）、模糊、深色，或从相册选一张自己的照片
- 黑胶盘面颜色可换：默认黑，另有白、红、蓝、紫、金等预设与自定义取色，支持透明直接透出背景
- 轻点黑胶播放 / 暂停，点封面以外的空白处切换歌词
- 封面自带白边时自动识别并裁掉，黑胶盘面比例更准
- 播放页禁用了长按选中文字与系统长按菜单，手势不再被系统抢走
- 歌词样式面板改为底部弹出，不再被歌词区裁切
- 修复连续切歌时偶发「先播上一首，过几秒才切到当前歌」
- 统一喜欢页与歌单操作按钮的尺寸
- 修复部分已知问题
