# v2.7.21

- 新增导入音源：设置页可导入洛雪（LX）音乐播放脚本，沙箱内运行后作为自定义音源参与聚合搜索与自动换源
- 音源一键检测：设置页探测各音源可用性与延迟，检测不可用自动停用、恢复正常自动重新启用，检测完成按延迟排序展示
- 音源支持自定义显示名（别名），留空用内置名或导入脚本自带名
- 播放界面显示当前实际取链音源标签，一眼看出这首歌走的是哪个源
- 切歌 / 暂停前 64ms 音频淡出，消除 Android WebView 硬截断产生的爆音与上一首残留尾音
- 封面取色（k-means）移入 Web Worker，消除切歌瞬间 200~400ms 的主线程卡顿，唱臂动画不再冻住跳帧
- 自动换源时单个音源搜索 6 秒超时即跳下一个源，不再因单源无响应一直卡 loading
- WebView 放开混合内容限制，导入音源返回的 http 直链可正常播放
- 搜索页键盘弹出时按返回键先清空输入，再按一次才退出
- 移除睡眠定时器与播放速度设置
